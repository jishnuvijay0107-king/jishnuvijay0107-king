## Featured project

### [LLM-Sentinel ↗](https://github.com/jishnuvijay0107-king/LLM-Sentinel)
**Prompt inspection and policy enforcement for LLM applications.**

A research prototype that inspects prompts before model generation. It combines Unicode normalization, rule matching, Base64 inspection, and heuristic risk scoring to produce **ALLOW**, **REVIEW**, or **BLOCK** decisions.

| Inspect | Decide | Explain |
| :--- | :--- | :--- |
| Analyze suspicious prompt patterns and encoded content. | Apply a shared inspection policy through a FastAPI service. | Surface matching evidence and record inspection events. |

**Explore the engineering:** [Implementation & setup](https://github.com/jishnuvijay0107-king/LLM-Sentinel#run-locally) · [Tests & evaluation](https://github.com/jishnuvijay0107-king/LLM-Sentinel#tests) · [Documented limitations](https://github.com/jishnuvijay0107-king/LLM-Sentinel#limits)

<sub>Python · FastAPI · HTML / CSS / JavaScript · Docker · pytest. Rule-based inspection is experimental; risk scores are heuristic.</sub>
